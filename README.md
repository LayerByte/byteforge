# BYTEFORGE

Software development agency website with interactive service, project, pricing, dashboard, and contact demo workflows.

## Demo Mode

This project runs in automatic Demo Mode. No registration, backend server, payment account, API key, OAuth provider, or external infrastructure is required.

## Features

- Preserves the supplied BYTEFORGE visual design
- Frontend-only demo interactions
- Reusable toast notifications
- Modal dialog support
- Simulated button actions
- Form validation and feedback
- Search/filter support where search fields exist
- LocalStorage demo state persistence
- Reset Demo Data control
- Responsive helper styles

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage

## How To Run

Open:

```text
index.html
```

The site starts in Demo Mode automatically.
